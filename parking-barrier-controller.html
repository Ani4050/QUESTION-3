Automatic Parking Barrier Controller

A Moore finite-state machine built from six D flip-flops and AND/OR/NOT gates. The same netlist drives the simulator, the circuit diagram and the test bench, so what you see is what is verified.

Safety rules and constraints

  1. Motors are decoded from mutually exclusive states, so both can never be on together.
  2. O·C = 1 is physically impossible, so it is treated as sensor failure: the FSM enters FAULT and stops the motors.
  3. FAULT is only left through Reset. Unused codes 101/110/111 also fall into FAULT.
  4. Vehicle on the loop while closing reopens the barrier (obstruction).
  5. Requests are accepted only in IDLE with barrier closed; presses in other states are ignored.
  6. Entry has priority if E and X are pressed together.
  7. A pass is counted once, on the falling edge of V, never while V stays high.
  8. If IDLE is reached with the barrier not closed (for example after reset), it closes itself.

Design decisions

  • Moore, not Mealy: outputs depend only on state, so motor and LEDs cannot glitch with a noisy sensor. Cost: one extra clock of latency, which is irrelevant for a mechanical barrier.
  • Encoding IDLE 000, OPENING 001, CLOSING 010, OPEN 011, FAULT 1xx. Q2 alone means FAULT, which keeps the fault logic tiny.
  • Helper flip-flops: SEEN (vehicle reached the loop), RE (re-opened after obstruction, blocks a second count), DIR (latched direction for the counter).
  • Combinational = decoders, next-state and output gates. Sequential = the six D flip-flops (Q2, Q1, Q0, SEEN, RE, DIR) and the counter register.
  • Known limit: no timeout, so the barrier stays open until a car has passed and left the loop.

Rebuild in Logisim / CircuitVerse

  1. Add input pins R, V, E, X, O, C, CLK and output pins from the Circuit section.
  2. Place the gates from the netlist (multi-input AND/OR allowed), wiring by name.
  3. Add six D flip-flops, all clocked by CLK, D inputs from D2, D1, D0, DSEEN, DRE, DDIR. Their Q outputs feed back as Q2…DIR. Reset is already in every D gate (synchronous).
  4. Counter: 4-bit register (enable = PASS, clear = R) fed by adder with B = DIR ? 0001 : 1111, plus saturation gating (hold at 15 when up, at 0 when down).
  5. Power-up: pulse R for one clock.
